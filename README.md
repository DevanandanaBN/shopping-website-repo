\# Shopping Website



A Django-based e-commerce website developed using Python and Django.



\## Features



\- User Registration and Login

\- Product Browsing

\- Product Details

\- Shopping Cart

\- Favourite Products

\- Product Categories



\## Technologies Used



\- Python

\- Django

\- HTML

\- CSS

\- JavaScript

\- SQLite



\## Project Structure



\- `ecommercewebsite/` - Django project

\- `shopsphere/` - Main Django application

\- `templates/` - HTML templates

\- `static/` - CSS and images



\## How to Run



1\. Open the project folder.

2\. Activate the virtual environment.

3\. Run the following command:



```bash

python manage.py runserver
